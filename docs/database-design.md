# SmartAssist Database Design

PostgreSQL is the spec database (see `database/schema.sql` for the generated
DDL). The demo environment runs the same SQLAlchemy models on SQLite
(`backend/data/smartassist.db`) with zero setup — switching is only a
`DATABASE_URL` change.

## Tables

| Table | Key columns | Notes |
|-------|-------------|-------|
| users | id, name, email (unique), password_hash, role, created_at | role = STUDENT \| TEACHER |
| student_profiles | id, user_id → users, age, preferred_format, learning_requirement | learning_requirement set by ML (EASY/MODERATE/HIGH) |
| subjects | id, name, description | 3 rows: Mathematics, English, Computer Science |
| lessons | id, subject_id → subjects, title, description, difficulty, position | 15 rows (5 per subject) |
| resources | id, lesson_id → lessons, type, title, content, media_url | type = TEXT \| SIMPLIFIED_TEXT \| VISUAL \| AUDIO \| SHORT_LESSON; 75 rows |
| quizzes | id, lesson_id → lessons (unique), title | 15 rows |
| questions | id, quiz_id → quizzes, question, option_a..d, correct_answer | 75 rows (5 per quiz) |
| attempts | id, student_id → users, quiz_id → quizzes, score, percentage, time_taken, attempt_number, created_at | one row per quiz submission |
| recommendations | id, student_id → users, lesson_id → lessons, resource_id → resources, recommended_format, difficulty, confidence, reason, created_at | generated by the ML module, reason always present |
| student_progress | id, student_id → users, lesson_id → lessons, progress_percentage, completed, updated_at | progress never decreases; ≥70% on quiz completes the lesson |

## Relationships

```
users 1 ──── n student_profiles
users 1 ──── n attempts, recommendations, student_progress
subjects 1 ── n lessons ── 1 resources (5 formats)
                │
                └── 1 quizzes ── n questions
```
